# quarkdoc-reader

This module contains tools for reading Quarkdown documentation generated by [quarkdoc](../quarkdown-quarkdoc).

Function documentation is read from `docs-index.json` index files, which quarkdoc emits
next to each documentation module's HTML pages. In a Quarkdown distribution they are located
at `docs/<module>/docs-index.json`.

An index carries, for each function of a Quarkdown module: its name, module,
parameters (with Markdown descriptions and properties such as optionality and allowed enum values),
and its full documentation content in Markdown. The format is defined by
[`docs-index.schema.json`](../quarkdown-quarkdoc/docs-index.schema.json), owned by the emitting plugin.

The main consumer is the [language server](../quarkdown-lsp), which relies on the index
for completion, hover tooltips, and diagnostics.
